# EMPIRE ZERO — ربات ساخت کشور (گروهی)

## اجرا
    pip install -r requirements.txt
    export BOT_TOKEN=... MONGO_URI=mongodb://localhost:27017 ADMINS=123456,789   # مالک (8925078035) همیشه ادمینه
    python bot.py
در BotFather گزینه‌ی Group Privacy رو خاموش کن تا دستورهای فارسی بدون اسلش هم دیده بشن.

## فایل‌ها
- config.py   ثابت‌ها: ساختمان، یگان، NPCها، نرخ‌ها، ارزها
- engine.py   موتور اقتصاد/جنگ + ارتقای شاخه‌ها + ساخت NPC
- eco.py      بانک مرکزی، بازار، ارز/توکن PHX، روزانه، کار، ماموریت
- reg.py      اعتبارسنجی نام و ضدسوءاستفاده‌ی ثبت‌نام
- commands.py دستورهای گروه (اسلش + فارسی)
- ui.py       منوی دکمه‌ای و اقدام‌های جنگ
- bot.py      اتصال، دکمه‌ها، اتحاد، حلقه‌های پس‌زمینه
- admin.py    پنل ادمین عمیق (/admin در پیوی ربات)
- db.py / core.py / util.py

## تنظیم تعادل
همه‌ی اعداد (پاداش NPC، نرخ بانک، نقدینگی بازار، سقف وام، ...) توی config.py هستن.
